# IPRN SMS Platform

This repository contains a scaffolded system for an IPRN (International Premium Rate Numbers) SMS platform based on the architecture you described.

High-level components:

- Core infrastructure (load-balanced web/API servers, DB cluster, SMS processing)
- Admin panel
- User portal
- Public REST API
- Message processing workers
- Billing and revenue-tracking pipeline
- Compliance and logging framework

See `docs/architecture.md` for details.
